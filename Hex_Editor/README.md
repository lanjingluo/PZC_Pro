# Hex Editor
一个 Windows 窗口应用，使用 Python + WinForms（pythonnet）编写。
## 运行环境
- Python 3.12（当前使用 Codex 自带运行时）
- 需要已安装 pythonnet（`pip install pythonnet`）
## 文件格式
本软件创建/保存的文件为自定义 `.hex` 文件。
`.hex` 文件结构（固定头部 + 数据）：
| 偏移 | 大小 | 说明 |
|------|------|------|
| 0 | 4 | 魔数 `HEX1`，标识这是本软件的 .hex 文件 |
| 4 | 8 | 内容类型（如 `PNG`、`HEXMAP`，右侧补空格） |
| 12 | 8 | 数据长度（字节，小端） |
| 20 | 可变 | 内容数据 |
六角格画布文档（类型 `HEXMAP`）的内容是一段 JSON：
```json
{"v": 5, "paper": "A4", "cols": 12,
 "cells": {"3,3": "树林", "4,4": ["山地", 5, -4]},
 "edges": {"3,3|4,4": "河流", "0,0|SW": "河流"}}
```
其中 `paper` 为 A1/A2/A3/A4 或 `CUSTOM`（自定义尺寸 `width`/`height`），`cols` 为横向格子数，`margins` 为网格距边框的边距。

- `cells`：**格子地形**，键是 "列,行"
- `edges`：**格边地形**，键是 "列,行|列,行"（两格之间）或 "列,行|方向"（地图边界）

两者的值都可以是地形名字（用默认消耗/修正），也可以是 `["地形名", 消耗, 修正]` 单独指定。未知名字会被原样保留并以灰色显示，不会静默丢失。v1~v4 的旧文件仍可正常打开。
## 当前功能
- 新建六角格画布（Ctrl+N）：选择 A1-A4 纸张 → 直接显示空白画布（不保存），调整格子数后点击“确认格子并保存”
- 从图片识别格子：点击顶部“从图片识别格子...”打开图片，自动识别横向格子数与网格距边框的边距，生成对应画布
- 画布顶部可输入或拖动滑块调节横向格子数（1-100），格子大小自动计算，整张画布始终被正六边形覆盖
- 画布渲染为位图缓存并防抖（拖动滑块或输入数字停止约 0.12 秒后才重绘），滚动与重绘不卡顿
- 画布缩放：顶部“缩小/放大/100%”按钮、视图菜单，或按住 Ctrl 滚动鼠标滚轮（10%–800%）
- 网格线条加粗（屏幕宽度约 2px），缩小到全景时依然清晰可见
- 保存默认目录为项目内 `saves` 文件夹（自动创建）
- 未保存提示：改动后标题栏显示 `*`，新建画布 / 打开其他文件 / 关闭窗口时会先询问是否放弃修改
- 每个格子都有编号（按行从左到右，从 1 开始）与属性（地形名字、移动力消耗、地形修正），相邻格子互相连接成图（每个格子最多 6 个邻居）
- 格子地形（左侧「格子地形」区）：树林（绿）/ 山地（棕）/ 城市（黑），点击格子即可上色；默认消耗 2/3/1，修正 -1/-2/-3
- 格边地形（左侧「格边地形」区）：河流（蓝），点击靠近某条**格边**的位置，这条边会加粗变蓝；默认跨边额外消耗 2、修正 -1
- 移动力：跨格消耗 = 目标格地形消耗 + 跨过那条边的额外消耗（空地按 1 计），并提供 `find_path()` 按消耗求最省路径（Dijkstra），会为了避开河流而绕路
- 面板实时显示选中格子的编号、坐标与三个地形属性、选中格边的信息，以及格子/格边地形数量统计
- 打开（Ctrl+O）：打开 `.hex` 文件（含六角格画布），或直接打开图片等原始文件查看
- 保存（Ctrl+S）/ 另存为（Ctrl+Shift+S）：生成 `.hex` 文件
- 导出原始文件（Ctrl+E）：从 `.hex` 中还原出原始类型的文件（画布可导出为 JSON）
- 十六进制视图：偏移列 + 十六进制 + ASCII 侧栏
- 大文件最多显示前 512 KB，避免界面卡顿
## 运行方法
方式一：双击 `run.bat`
方式二：在 PowerShell 中运行
```powershell
python main.py
```
## 文件说明
- `main.py`：应用主体（窗口、菜单、六角格画布、.hex 读写）
- `hexformat.py`：.hex 容器、A1-A4 纸张换算、六角格布局与画布文档逻辑
- `imagedetect.py`：从图片识别六角格网格（列数与边距）
- `hexmap.py`：格子模型 HexCell（编号、坐标、地形属性）与地图图结构 HexMap（相邻关系、地形统计）
- `run.bat`：双击启动脚本
