# Hex Editor
一个 Windows 窗口应用，使用 Python + WinForms（pythonnet）编写。
## 运行环境
- Python 3.12（当前使用 Codex 自带运行时）
- 需要已安装 pythonnet（`pip install pythonnet`）
## 文件格式
本软件创建/保存的文件为自定义 `.hex` 文件。
`.hex` 文件结构（固定头部 + 数据）：
| 偏移 | 大小 | 说明 |
|------|------|------|
| 0 | 4 | 魔数 `HEX1`，标识这是本软件的 .hex 文件 |
| 4 | 8 | 内容类型（如 `PNG`、`HEXMAP`，右侧补空格） |
| 12 | 8 | 数据长度（字节，小端） |
| 20 | 可变 | 内容数据 |
六角格画布文档（类型 `HEXMAP`）的内容是一段 JSON：
```json
{"v": 2, "paper": "A4", "cols": 12}
```
其中 `paper` 为 A1/A2/A3/A4 或 `CUSTOM`（自定义尺寸 `width`/`height`），`cols` 为横向格子数，`margins` 为网格距边框的边距（可省略）。
## 当前功能
- 新建六角格画布（Ctrl+N）：选择 A1-A4 纸张 → 直接显示空白画布（不保存），调整格子数后点击“确认格子并保存”
- 从图片识别格子：点击顶部“从图片识别格子...”打开图片，自动识别横向格子数与网格距边框的边距，生成对应画布
- 画布顶部可输入或拖动滑块调节横向格子数（1-100），格子大小自动计算，整张画布始终被正六边形覆盖
- 画布渲染为位图缓存并防抖（拖动滑块或输入数字停止约 0.12 秒后才重绘），滚动与重绘不卡顿
- 画布缩放：顶部“缩小/放大/100%”按钮、视图菜单，或按住 Ctrl 滚动鼠标滚轮（10%–800%）
- 网格线条加粗（屏幕宽度约 2px），缩小到全景时依然清晰可见
- 保存默认目录为项目内 `saves` 文件夹（自动创建）
- 打开（Ctrl+O）：打开 `.hex` 文件（含六角格画布），或直接打开图片等原始文件查看
- 保存（Ctrl+S）/ 另存为（Ctrl+Shift+S）：生成 `.hex` 文件
- 导出原始文件（Ctrl+E）：从 `.hex` 中还原出原始类型的文件（画布可导出为 JSON）
- 十六进制视图：偏移列 + 十六进制 + ASCII 侧栏
- 大文件最多显示前 512 KB，避免界面卡顿
## 运行方法
方式一：双击 `run.bat`
方式二：在 PowerShell 中运行
```powershell
python main.py
```
## 文件说明
- `main.py`：应用主体（窗口、菜单、六角格画布、.hex 读写）
- `hexformat.py`：.hex 容器、A1-A4 纸张换算、六角格布局与画布文档逻辑
- `imagedetect.py`：从图片识别六角格网格（列数与边距）
- `run.bat`：双击启动脚本
